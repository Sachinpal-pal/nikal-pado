# Nikal Pado

Nikal Pado is a simple web application built for the Hacktoberfest Touch Grass challenge. It helps you plan a quick outdoor break based on your available time and interests.

## Features
- Quick outdoor activity planning based on location, weather, and time.
- Interactive checklists for your outing.
- Simple local field journal to save your notes.

## Tech Stack
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone the repository.
2. Open index.html in any web browser.
